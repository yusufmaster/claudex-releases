# ClaudeX

ClaudeX is our desktop app for Claude Code, built by MasterXStudios: several Claude accounts side by side, your chats grouped by folder, model and effort controls, Ultracode, image and video attachments, and live context and plan usage.

## Install

1. Open [Releases](https://github.com/yusufmaster/claudex-releases/releases/latest) and download `ClaudeX-Setup-<version>.exe`.
2. Run it. Windows may say it protected your PC, because the app isn't code-signed: click **More info**, then **Run anyway**.
3. If Claude Code isn't on your PC yet, ClaudeX offers to install it with Anthropic's official installer. Then sign in with your own Claude account.

ClaudeX updates itself. Every time it starts, it checks this page for a newer version, downloads it in the background and restarts into it once Claude isn't mid-reply.

This repo only holds the installers.
